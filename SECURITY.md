# Security Policy

## Reporting a vulnerability

Please do not disclose vulnerabilities in a public issue. If private vulnerability reporting is enabled for this repository, use **Security → Advisories → Report a vulnerability** on GitHub. Include the affected file or commit, impact, and steps to reproduce. Avoid attaching personal data or secrets.

If private reporting is not available, contact the repository owner through GitHub before sharing technical details publicly.

## Supported versions

Only the current default branch is maintained. No release/support policy is promised yet.
